# ①課題名
自社である株式会社いきかたのLP

## ②課題内容（どんな作品か）
- 会社として大事にしている想いを冒頭に記載し、何ができる？より、どんな変化を生むのか？を重視しました。

## ③アプリのデプロイURL
デプロイしている場合はURLを記入（任意）

## ④アプリのログイン用IDまたはPassword（ある場合）
- ID: 無し
- PW: 無し

## ⑤工夫した点・こだわった点
- サイト中段の３つの事業紹介では、写真と文章を交互にすることで、視認性を高くしました。
- 文章の高さと写真の高さを揃えることで、全体をすっきりとまとめられました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 写真の高さを文章に合わせようとしたとき、写真が勝手にトリミングされて、本来の写真の一部のみが表示される形になってしまいました。
- 写真の解像度も含め、元画像を維持した形で掲載できるようにしたいです。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
- 全体的に色味が少ないシンプルなサイトになりました。
- 淡い色でも、もう少し使えたらいいかも？と思ったのですが、まずはSimple is BESTで！
